One out-of-office auto-reply, as if a houseplant sent it — the funniest one we could think of.

> Out of office: I have not been watered since March. If you are reading this, you are closer to water than I am.

Entry for the make.fun competition [The Houseplant Out-of-Office](https://make.fun/bounty/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047).

## How it works

`main.ts` (Node 22, stdlib only) writes the message to `/output/entry.txt`.
No network, no randomness, no clock — two runs write byte-identical output.

See [METHOD.md](METHOD.md) for the 30-candidate tournament and the reasoning.
